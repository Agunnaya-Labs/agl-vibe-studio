## 🎨 Visual Identity & Theme: *Immersive UI*

Agunnaya Labs Studio features a tailored **Immersive UI** style, crafted to provide a deep developer experience with visual references to professional IDEs and terminal environments:

*   **Atmospheric Ambient Glows**: Real-time canvas radial glows shifting dynamically from Base Blue (`#0052FF`) to Mystical Purple (`#A855F7`), creating depth without clutter.
*   **Tactile Geometric Layout**: Sleek border divisions (`border-white/10`) resting on an ultra-dark background (`#050505`) with `#0a0a0a` sidebar containment.
*   **Vibrant Glassmorphism**: Cards and widgets styled as unified physical panels (`glass-panel`), complete with interactive micro-hover states and glowing soft-blue drop shadows.
*   **Refinement over Popups**: All native browser alert loops are deprecated and replaced with a custom **Toast Notification Subsystem** built with reactive entry animations (`animate-fade-in`), clear-cut status borders, and interactive exit controls.
*   **Dual Network Flexibility**: Toggleable environment support spanning **Base Mainnet** and **Sepolia Sandbox** with real-time status cues and mock faucets for developers.

## 🚀 Key Modules & Capabilities

### 1. ⚡ Bonding Curve Launchpad & AI Architect
*   **Manual Deployment**: Launch tokens with real initial seed buys and custom mathematical models.
*   **AI Smart Contract Generator**: Describe your token mechanics in plain English (e.g., tax structures, lock periods, and custom curve rates), and watch the integrated **Gemini model** formulate actual production-ready Solidity-inspired structures.

### 2. 🧠 AI Agent Studio
*   **Custom Agent Creation**: Initialize autonomous on-chain agents with custom symbols, specialized system prompts, and strict task boundaries.
*   **Subscription Mechanics**: Set custom usage fees (in ETH) and track active agent query volumes, real-time response histories, and accrued developer revenue.

### 3. 🏦 DeFi Engine & Automated Market Maker (AMM)
*   **AMM Swapping**: Perform instant low-slippage swaps between simulated ETH and native AGL utility tokens.
*   **Staking Vaults**: Lock AGL inside safe smart-yield vaults to generate compounding high-yield APY rewards.

### 4. 🗳️ DAO Builder & Governance
*   **Decentralized Coordination**: Create specialized DAOs with unique proposal thresholds, voting weights, and lock parameters.
*   **Active Balloting**: Propose treasury distributions or protocol upgrades, and submit weighted cryptographic ballots in real-time.

*   **Art Collections**: Mint and host modern ERC-721 collections with dynamic metadata schemas and set public minting pricing.

### 7. 🛡️ Factory Tuning (Admin Panel)

## 🛠️ System Architecture & Stack

Agunnaya Labs Studio is engineered as a robust full-stack containerized web applet:

*   **Frontend**: React 19 + TypeScript, designed using Tailwind CSS (v4) with fully responsive utility classes.
*   **Backend**: Production-ready Express.js proxy serving client bundles and handling server-side logic securely.
*   **AI Core**: Google GenAI TypeScript SDK (`@google/genai`) with secure server-side environment variables protecting raw API keys.
*   **Animations**: Staggered physical entry movements managed dynamically by the `motion` framework.
*   **Data Visualization**: High-fidelity line metrics and custom analytical trend lines structured with `recharts`.

## 💻 Developer Commands & Scripts

Run the workspace locally with standard package control managers:

| Command | Action |
| :--- | :--- |
| `npm run dev` | Boots up the local developer server using `tsx` on port `3000`. |
| `npm run build` | Compiles front-end assets with Vite and bundles the Node server as a single `.cjs` file using `esbuild`. |
| `npm run start` | Executes the optimized, standalone production build. |
| `npm run lint` | Runs type audits to guarantee high code safety. |
| `npm run clean` | Purges existing build outputs (`dist/`) and cached server scripts. |
